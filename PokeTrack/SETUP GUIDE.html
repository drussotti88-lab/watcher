Setup guide

PokeTrack

Reads your inboxes for Pokémon Center and Target order mail, tracks every open pre-order, and tells you how much cash you need ready on each release date. Runs entirely on your own computer.

1

Install Python

PokeTrack is written in Python, and Windows doesn't ship with it. This is a one-time, five-minute install. If you already have Python, skip to step 2.

  1. Go to python.org/downloads and click the big yellow Download Python button.
  2. Run the file it downloads.
  3. On the very first installer screen, tick “Add python.exe to PATH.” It's a small checkbox near the bottom and it is easy to miss.
  4. Click Install Now and let it finish.
If you miss that checkbox PokeTrack won't be able to start, and you'll get a “Python is not installed yet” message. Re-run the installer, choose Modify, and turn the PATH option on.
2

Start PokeTrack

Open the PokeTrack folder and double-click START PokeTrack.bat.

A black console window opens and stays open — that window is the app running, so leave it alone. Your browser opens to the dashboard a second later. To stop PokeTrack, close the console window.

Nothing else needs installing. There is no pip, no setup command, and no internet connection required beyond reading your own email.

Want to see it working before connecting real email?

Open the console window in that folder and run python tests\seed_demo.py. That loads a handful of fake orders so you can poke at every screen. Delete the data folder afterwards to wipe it clean.

3

Get an app password

Email providers won't let an app sign in with your normal password any more. Instead you generate a separate 16-character password that works only for mail apps and can be revoked at any time without changing your real password. You need one per inbox.

Gmail

  1. Turn on 2-Step Verification first — app passwords don't exist without it.
  2. Google Account → Security
  3. Search the page for App passwords
  4. Name it “PokeTrack”, then copy the code

Outlook / Hotmail

  1. Turn on two-step verification first
  2. Microsoft account → Security
  3. Advanced security options
  4. Under App passwords, create a new one

Yahoo / AOL

  1. Account Info → Account Security
  2. Generate app password
  3. Pick “Other app”, name it PokeTrack
  4. Copy the code it shows you

Copy the code with the spaces removed. It only ever gets shown once, so if you lose it, just generate another.

4

Add your inboxes

Click Email accounts in the sidebar. Enter the address and the app password. Leave the IMAP server blank — PokeTrack works it out from the address for every common provider.

Hit Test connection only first. If it comes back green, hit Save inbox. Repeat for each address your orders land in — there's no limit on how many you add.

How far back to look defaults to 540 days. Raise it if you want older order history pulled in; the first scan just takes longer.

5

Run a scan

Hit Scan my email in the sidebar. PokeTrack asks each mail server only for messages from the senders your rules mention, downloads those, and reads them. Everything it finds is stored on your computer.

The first scan is the slow one — a few minutes if you have a lot of history. After that it only fetches what's new, so later scans take seconds. Run it whenever you want; it never downloads the same message twice.

6

Add release dates

This is the piece PokeTrack can't get from email. Order confirmations rarely say when a pre-order actually ships — so you type it in once per product, and every matching pre-order lands on that date in the cash timeline.

Go to Release dates and add:

Example entry ProductMega Evolution Elite Trainer Box
Release date2026-09-26
Match textmega evolution
Estimated price59.99

Match text is the important field. It's the words PokeTrack looks for in your order's line items. Keep it short and distinctive — mega evolution catches the product no matter how the store spelled out the rest of the title. The full name usually matches nothing, because Target and Pokémon Center never write it the same way.

Change a date later and the money moves with it immediately. Nothing needs re-scanning.

7

Write rules

A rule decides which emails count and what they mean. Five are set up already — four for Pokémon Center and one for Target. Rules are checked from the lowest order number upward, and the first one that matches an email wins.

Every condition you fill in must pass. A blank condition is ignored. Inside one box, comma-separated terms mean “any of these.”

Rule: Pokémon Center pre-orders Sender containspokemoncenter.com
Subject containspre-order, preorder, pre order
Treats email asA pre-order
Card chargedWhen it ships
Order10
Rule: Target Pokémon orders Sender containstarget.com, oes.target.com
Subject containsorder, thanks for your order
Must NOT containcancel, delivered, return
Body containspokemon, pokémon
Order30

That second one shows the trick for stores that sell more than Pokémon: the body contains condition means a Target order for bath towels is ignored while a Target order for an Elite Trainer Box comes through.

Test before you trust

Rules → Test a rule lets you paste an email — or pick one PokeTrack already downloaded — and see exactly which rule catches it, which conditions passed, and what would be pulled out of it. Use it any time a rule isn't behaving.

After you change a rule

Hit Re-apply rules to email already downloaded on the Rules page. It rebuilds your orders from the mail already on your machine, so you don't have to scan your inbox again. Orders you edited by hand or added notes to are left alone.

Reading the dashboard

What you seeWhat it means
Still owedEvery dollar committed to an order that hasn't hit your card yet.
Due in 30 daysThe slice of that arriving in the next month. This is the “do I have enough” number.
Next charge dateThe soonest day money comes out, and how much.
Cash needed by release dateOne bar per date. The table under it names the orders in each bar, so you can click straight through.
Shipped vs still pendingOrder value split by status, so you can see how much is genuinely in flight.
No date yetMoney owed on pre-orders whose products have no release date yet. Add one and it moves onto the timeline.

Pokémon Center authorizes your card at order time but doesn't actually charge until the item ships, which is why pre-orders count as owed rather than spent. When a shipping email arrives, PokeTrack flips that order to charged automatically.

Using it

When it gets it wrong

Retailers change their email templates constantly, so the parser will occasionally miss something. It's built to flag that rather than quietly guess.

  • Needs review in the sidebar lists every email a rule caught but the parser couldn't fully read, with a note on what was missing.
  • Open any order and edit any field. Once you do, that field is locked — no future scan or rebuild will overwrite it.
  • Missing an order entirely? Orders → Add an order by hand. Give it a release date and it joins the timeline like any other.
  • Line items missing? Add them on the order page. That's what release-date matching reads.

Good to know

Your data

Everything lives in the data folder next to the app: your orders, your rules, and the text of the emails PokeTrack read. Nothing is uploaded anywhere, and the app makes no network connection except to your own mail server.

Your app password is obfuscated in that database rather than stored as plain readable text. That protects against a casual glance, not against someone who already has your Windows account — which is exactly why you use an app password you can revoke instead of your real one.

To back it up: copy the data folder somewhere safe. To start over: delete it — a fresh one is created next time you launch.
